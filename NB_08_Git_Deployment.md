# NB_08 – Git & Deployment

## Banking Data Platform – Git Workflow

Feature Branch:
feature/nb08-git-workflow

Workflow:

main
  ↓
feature branch
  ↓
development changes
  ↓
git add
  ↓
git commit
  ↓
git push
  ↓
Pull Request
  ↓
Code Review
  ↓
Merge to main

Purpose:
Use feature branches to safely develop and review changes
before merging them into the main branch.
